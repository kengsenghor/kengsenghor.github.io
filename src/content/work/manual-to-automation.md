## Problem

Testing was largely manual across web and mobile, and it did not scale across several product lines in regulated software or across regions.

## What I did

I built the automation function from zero: roadmaps, KPIs and metrics, and a move from manual QA to automation engineering. I later led up to ten testers across Malaysia, the UK, the US and India, recruiting, coaching and growing them into automation practitioners. I rolled out a centralized CI/CD framework for API and UI automation with performance test automation, and delivered Rapid Software Testing training.

## Result

Testers grew into automation practitioners, risk-based testing maturity rose, and the work supported external audit readiness.
